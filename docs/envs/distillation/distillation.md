# Distillation Benchmark

## Gymnasium Environment for a Simulated Distillation Column Process

This environment simulates the dynamics of a distillation column process using pre-trained TensorFlow models. The models were trained on synthetic data generated by a gProms (TM) model of the distillation process applied to separate methanol and water.

## Environment Description

### State Space

The state space of the distillation process is defined as follows.

| Num | Observation                | Min   | Max   |
|-----|----------------------------|-------|-------|
| 0   | Reflux Ratio               | 0.0   | 1.0   |
| 1   | Input Energy Rate          | 0.0   | 1.0   |
| 2   | Mass Flowrate              | 0.0   | 1.0   |
| 3   | Water Fraction             | 0.0   | 1.0   |
| 4   | Ethanol Fraction           | 0.0   | 1.0   |
| 5   | Objective Mass Flowrate    | 0.0   | 1.0   |
| 6   | Objective Water Fraction   | 0.0   | 1.0   |

### Action Space

The system is controlled by the following continuous (floating point) control actions.

| Num | Action                      | Min   | Max   |
|-----|-----------------------------|-------|-------|
| 0   | Control Reflux Ratio        | 0.0   | 1.0   |
| 1   | Control Input Energy Rate   | 0.0   | 1.0   |

### Reward Function

The reward is computed based on the deviation of the current process outputs from their objectives and regularization on the control actions. (See environment code for details.)

### Starting State

Depending on the config field 'init_method', the starting state is either drawn as a 'random' sample or set by a 'fixed' sample (as defined by the 'initial_observation' field).

### Episode End

Depending on the config field 'max_episode_steps', the episode is either terminated when the maximum step limit is reached or is run infinitely.
